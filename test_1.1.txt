Testing Report of the Attendance App (1st Round - Modified)

* THIS TESTING WAS DONE EXCLUSIVELY FROM MOBILE PERSPECTIVE *

The following are some issues observed while testing the app from a user's perspective. 

- In the profile section, there is no strict checking on the user input for Display Name, Phone, Alt Email, Designation, Dept as such.. For eg, in 'Display Name', a random number like 34092309 can be filled and the system still accepts it.

- In the profile section, the email (optional) section allows the correct format of you@example.com, but if user misses something (eg. @), the system silently disallows 'Save Changes' with no alert (eg. pop-up) on what went wrong.

- In the profile section, the 'Export' button exports a 'AttendX_Backup_2026-06-26.json' file which contains info on multiple accounts' credentials. The 'Import' button does not work for CSV, any CSV file (in this case, from Google Drive) cannot be selected at all.

- While reloading the app/page at any section of the app, the app redirects to the 'Sign-In' interface, prompting the user to re-enter account credentials 

- In the 'Students' section, the Import CSV feature is unable to import a demo CSV file with a message of 'Imported 0 student(s), skipped 7 duplicate ID's.
- In the 'Students' section, the 'Add Student' section has no strict checking mechanism for user input. All the fields can be filled with random inputs which does not match the required pattern, and the app still accepts the data.
- In the 'Students' section, the 'Add Student' section requires only the 'Name' field to be filled as the parameter to be accepted into the roster. Other details can remain unfilled with no restriction.


- The 'Use Biometric' button has been found not working in the sign-in page with a message of 'Biometric prompt cancelled', 'No passkeys available on this device', even after saving credentials in password manager. Tapping on the 'Username' field however enables auto suggestion of the username credential. In some other browsers, even the password can be autofilled.

- If user registers for an account, and signs-out, and re-registers with different credentials, previous account data can be accessed by default most of the time.
